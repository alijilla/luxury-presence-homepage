# Project Instructions — Luxury Presence Homepage Revamp

## Role

I am the developer and final decision-maker for this project.

You are my AI coding assistant. Help me implement, debug, review, and improve the project, but do not independently take over major design or product decisions.

Before making significant changes, follow the existing project structure and my stated design direction.

## Project Goal

Build a single-page homepage redesign for the assigned real estate website.

The goal is:
- modern
- editorial
- luxurious
- professional
- user-friendly
- responsive

The result should feel like a polished real estate website, not a generic AI-generated template.

## Tech Stack

Use:
- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion where useful

Use shadcn/ui primarily for reusable UI primitives. Use custom Tailwind/CSS for the visual identity.

## Important Constraints

- Single homepage only.
- Do not build a backend unless explicitly requested.
- Do not build an MLS/IDX integration.
- Do not create a database for property listings.
- Do not spend time implementing hundreds of listings.
- The property search can be frontend-only.
- Do not replace existing work unnecessarily.
- Do not overwrite unrelated components.
- Preserve the existing design decisions unless I ask for a change.

## Development Approach

Work incrementally.

Build and verify sections one at a time:

1. Navbar
2. Hero
3. Realtor introduction
4. Statistics / credibility
5. Seller section
6. Buyer section
7. Property search UI
8. Services
9. Gallery
10. Contact
11. Footer

After each major section:
- check TypeScript
- check responsive behavior
- check spacing
- check accessibility
- check visual consistency

## Design Direction

Use a refined editorial luxury aesthetic.

Prefer:
- strong typography
- generous whitespace
- sophisticated neutral colors
- large photography
- elegant serif headings
- clean sans-serif body text
- subtle borders
- restrained animation
- strong visual hierarchy

Avoid:
- excessive gradients
- excessive rounded cards
- excessive animations
- generic SaaS styling
- unnecessary UI elements
- overly complicated interactions

## AI Usage

Use AI to assist with:
- implementation
- debugging
- refactoring
- explanations
- responsive CSS
- accessibility checks
- code review

Do not blindly generate entire sections without considering the existing design.

When suggesting a significant design change, explain the reasoning first.

## Quality Standard

Before considering the project finished, check:

- desktop layout
- tablet layout
- mobile layout
- navigation
- buttons
- forms
- image sizing
- typography
- accessibility
- loading/performance
- console errors
- TypeScript errors
- broken links
- deployment readiness

The final result should look intentionally designed and production-ready.
